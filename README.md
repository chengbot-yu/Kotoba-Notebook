# ことばノート — 日本語単語帳

一个**完全属于你自己**的日语单词记忆 / 复习网页应用。

> 不是在线词典，不是 AI 词汇解释工具。
> 词性、翻译、自他动词、例句、备注全部由你亲自填写，网页不做任何判断、纠正或自动生成。
> **记录自己的词 → 找回忘记的词 → 不断重复 → 长期积累**

数据 100% 保存在浏览器本地（IndexedDB），完全离线可用，不需要登录、注册、联网、后端或任何 API。

## 功能一览

| 模块 | 说明 |
|---|---|
| ホーム | 今日日期（日语曜日：月火水木金土日）、今日新增/复习、连续学习、累计词汇、待复习、每日目标进度、最近解锁成就 + 下一目标 |
| 単語 | 全量词库：搜索（单词/读音/翻译/标签/备注）、按日期/标签/掌握状态/词性/自他动词筛选、待复习过滤、多种排序 |
| 復習 | 三种训练：日本語→中国語、中国語→日本語、単語を思い出す（纯回忆）；「答えを確認」后由你自己判断 覚えていた / 忘れていた |
| カレンダー | 学习日历（GitHub 风格热力等级 + 毛玻璃），星期表头恒为 月火水木金土日；点选某天查看当天详情与单词 |
| 実績 | 全部基于真实数据解锁：词汇里程碑、连续学习、复习次数、早起き/夜の学習、忘却から復活、目標達成 |
| 統計 | 累计词汇/学习天数/最长连续/累计复习/本周/本月、过去 7 天堆叠柱图、过去 30 天迷你柱图、新增/复习比例 |
| 設定 | 深色/浅色主题、默认训练方向、顺序、每日目标、通知开关、数据导出/导入/清空 |

### 核心规则

- **录入极简**：最低只填「単語」即可保存，其余字段随时可补充编辑。
- **重复检测**：录入已存在的单词时提示「この単語はすでに登録されています」，引导查看原词或强制新增，默认不制造重复数据。
- **复习调度**：忘记 → 当天立即回炉（同一次训练中会再出现）；记住 → 间隔按 1 / 3 / 7 / 14 / 30 / 60 / 120 天递增。
- **掌握状态**：未复习 → 学习中 → 容易忘记 / 熟悉 → 已掌握，完全由你的复习行为决定。
- **用户数据不可侵犯**：网页绝不自动修改你填写的任何字段。

## 数据存储方案

- **IndexedDB**（数据库 `kotoba-notebook`）：
  - `words` — 单词（id 主键）
  - `reviews` — 复习记录（id 主键，含 wordId/date/result/mode）
  - `studyDays` — 每日学习汇总（date 主键：newWords/reviewCount）
  - `achievements` — 已解锁成就（id 主键 + unlockedAt）
  - `settings` — 轻量设置与成就标记（key 主键）
- **localStorage** 仅保存一份主题/方向/目标等偏好设置的镜像。
- **数据备份**：設定 → データをエクスポート 导出完整 JSON；インポート 支持「置換 / マージ」两种模式恢复；清空数据需要输入「削除」双重确认。

## 复习机制（SRS）

- 待复习 = 从未复习过的词 + 到期（nextReviewAt ≤ 今天）的词。
- 训练中点击 **忘れていた**：`forgotCount+1`、连续记住数归零、到期日=今天，并**在同一会话中插入到前方再次出现**（至多 2 次，避免死循环）。
- 点击 **覚えていた**：连续记住数 +1，下次复习间隔按 `1,3,7,14,30,60,120` 天递增。
- **优先级**：重要 ⭐ / 容易忘记 🌀 标记、近期忘记过的词、从未复习的词 → 排序更靠前。
- **掌握状态**：连续记住 ≥5 → 已掌握；≥3 或复习 ≥6 次 → 熟悉；忘记 ≥3 次且未巩固 → 容易忘记；其余 → 学习中。

## 成就机制（実績）

所有成就由 `achievements.ts` 在每次写入后基于真实数据判定，解锁即持久化并弹出庆祝卡片：

- 词汇：初めの一歩 / 10語 / 50語 / 100語 / 500語 / 1000語
- 连续：3日連続 / 7日連続 / 14日連続 / 30日連続 / 100日連続
- 复习：初回復習 / 100回復習 / 500回復習
- 趣味：早起き（5–11時学習）/ 夜の学習（22–5時学習）/ 忘却から復活 / 目標達成

---

## 日历机制

- 星期表头固定 **月 火 水 木 金 土 日**（周一起始）。
- 每天格子按当天学习量（新增+复习）分 0 / 1–5 / 6–10 / 11–20 / 20+ 五档显色；未来日期淡化。
- 点选日期显示：日期+曜日、新增数、复习数、截至该日的连续天数、当天记录的单词列表。
- 学习日历数据来自 `studyDays`，与录入/复习原子同步。

## 已知限制

- 数据与浏览器绑定：换浏览器/清浏览器数据前请先「データをエクスポート」备份。
- 复习间隔基于「天」粒度；一天内多次复习同一词会计入复习次数但调度以天为单位。
- 删除单词会保留历史复习记录（统计保持诚实），但日历中不再列出该词。
- 通知提醒仅在该页面打开时触发（无后台推送，纯本地产品原则）。
- 词库很大时列表渲染为一次性全量渲染（数千词量级流畅，十万级未做虚拟滚动）。
